# Illustration

`public/images/kitchen-banner.png` is an original AI-generated illustration made for SnoiCafe. It contains a cheerful cooking pot, vegetables, and a warm cream background. It is decorative, contains no family data, and is intentionally public with the app code.

Tool: built-in image generation. Final art direction: a cute, cartoon-style family kitchen banner; wide landscape crop; smiling orange cooking pot and friendly tomatoes, herbs, greens and cooking utensils on the right; dark warm hand-drawn outlines; soft sage, peach and cream palette; uncluttered left area for a heading; no text, no lettering, no watermark. The final image was edited from an earlier generated kitchen banner to give it friendlier cartoon faces and softer, rounder shapes.

Preview dish illustrations use platform emoji; real kitchens start without sample dishes and display the chef's uploaded photos. Icons are provided by Lucide (ISC license). Typography uses system Helvetica/Arial and Chinese system fallbacks, with no external font requests.
